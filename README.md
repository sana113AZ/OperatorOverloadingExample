# OperatorOverloadingExample
A C++ project that demonstrates class usage, constructors, destructors, and operator overloading. The program defines a class testclass with methods to set and print data, supports assignment operator =, and overloads the division operator / with error handling. It is a simple example for practicing Object-Oriented Programming (OOP) in C++.
# OperatorOverloadingExample
A simple C++ project that demonstrates **class usage, constructors, destructors, and operator overloading** (division operator).

---

## 📌 Description
This project defines a class `testclass` with:
- Default and parameterized constructors
- Destructor
- Setter and printer functions
- Assignment operator (=)
- Overloaded division operator (`/`) with error handling (division by zero)

---

## 📂 Files
- `class.h` → class definition
- `class.cpp` → class implementation
- `main.cpp` → main program to test the class
